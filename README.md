# albw-tracker

100% checklist for *The Legend of Zelda: A Link Between Worlds* (3DS) that reads save files. Layout based on the
[Pokémon Emerald 100% checklist](https://pokemoncompletion.com/completion/Emerald).

## Usage

1. Back up the save with [Checkpoint](https://github.com/BernardoGiordano/Checkpoint).
2. Copy `3ds/Checkpoint/saves/0x00EC3 The Legend of Zelda/` off the SD card.
3. Load the folder with **Load save folder** or drag and drop. A folder with several backups gives a backup picker.

`SaveCommon.bin` is needed to show whether a file has beaten the game.

Loading a save sets the ticks for every check the save records. Other ticks are left as they are. Ticks, view settings
and the file details are stored in localStorage; save files are not. Export / Import copies ticks and settings as
text.

```
npm start                 # http://localhost:8080
npm run check-save -- <folder>
```

`src/checks.js` is generated by `npm run gen` from
[albw-archipelago](https://github.com/randomsalience/albw-archipelago) (location flags) and
[z17-randomizer](https://github.com/rickfay/z17-randomizer) (vanilla items and regions), cloned into
`tools/.cache/`. Flags that only exist in randomized games are replaced in `tools/gen-checks.mjs` with the vanilla flag
or an inventory check.

Hints in `data/hints.json` are based on
[Zelda's Palace](https://www.zeldaspalace.com/alinkbetweenworlds/piecesOfHeart.php),
[GameSkinny](https://www.gameskinny.com/tips/a-link-between-worlds-piece-of-heart-locations-guide/),
[Prima Games](https://primagames.com/tips/legend-zelda-link-between-worlds-how-get-pegasus-boots) and
[GamingBolt](https://gamingbolt.com/the-legend-of-zelda-a-link-between-worlds-mega-guide-collectibles-locations-rupees-more).

## Not tracked

StreetPass battles and repeatable minigame rewards. The save does not store them.
